# 卢夫人墓项目资料基准

## 主依据

《陕西咸阳唐李将军魏公故卢夫人墓发掘简报》是本项目墓葬形制、尺寸、葬具、葬式、随葬品类别与位置的首要依据。

## 已核验的墓室数据

- 墓室进深 3.68 米、宽 3.04 米、高 2.52 米。
- 木棺一具，南北向置于墓室西侧砖砌棺床上。
- 木棺长约 2.64 米、宽 0.78-1 米。
- 随葬品大多数位于墓室东南隅和壁龛。
- 墓室东北隅有木箱残留遗迹，长约 1.05 米、宽约 0.8 米。
- 墓志及器物相对位置以简报图一一为主。
- 耕土层厚约 0.32 米，墓口开于耕土层下。
- 垆土层厚约 0.30 米，墓葬向下打破该层。

## 形态自然化依据

- 三个过洞均为斜向拱顶土洞。
- 甬道为拱顶土洞。
- 墓室为拱顶、直壁，直壁局部坍塌。
- 第三天井东、西两壁略有损坏。
- 东一号龛顶部略有坍塌。
- 西一号龛壁面略有坍塌。
- D1、D2为早期盗洞，应与墓葬原生结构区分表达。

## 数据等级

- `measured`：简报明确记载的实测数据。
- `scaled-from-plan`：依据简报比例平面图推算的位置或尺寸。
- `illustrative`：仅用于表达类别和空间关系的示意细节。
